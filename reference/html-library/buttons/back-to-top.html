Overview

Panel ke andar content scroll hota hai. Neeche jaate hi button dikhega.

Usage

Long pages par back-to-top button user ko turant upar le jata hai.

Accessibility

Hidden state me button tabindex -1 aur aria-hidden hota hai.

Motion

prefers-reduced-motion on hone par smooth scroll off ho jata hai.
